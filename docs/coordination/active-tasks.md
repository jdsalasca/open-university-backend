# Registro de tareas

Las tareas activas, propietarios, claims de archivos, dependencias y checkpoints viven en
Harness Moon. Este archivo es una entrada estable para colaboradores: consulta Harness y
reclama un alcance antes de modificar archivos.

No guardes aquí nombres de usuario, IDs de sesión o tarea, rutas locales, logs, tokens ni
capturas de herramientas. Al completar un cambio, deja el resultado, SHA y CI en Harness;
actualiza la hoja de ruta del producto solo cuando el hito sea útil para sus lectores.
